# Pinned Python tooling for the validation toolbox (tools/toolbox/Dockerfile).

# scripts/toolbox.sh hashes this file into the image tag, so a bump here names
# a different image and rebuilds it on the next gate run rather than whenever
# somebody remembers to force one.
#
# PyYAML is already an ansible-core dependency. It is pinned explicitly because
# scripts/test_container_security.sh and scripts/promote_artifacts.py import it
# directly, and a gate's own imports should not depend on what another package
# happens to pull in.
#
# requests is here for the same reason but one step removed:
# tests/test_dynamic_dns.py execs roles/dynamic_dns/templates/dynamic_dns.py.j2
# in-process, and that template imports it. On VM1 the dependency is satisfied
# by the distro package; here it has to be installed for those tests to load at
# all. Every other import across the suites and the templates they exec is
# standard library.
